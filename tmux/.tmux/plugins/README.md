# tmux plugins (vendored)

Managed by tpm (`prefix+I` to install, `prefix+U` to update). Vendored here as
plain tracked files rather than submodules, so a fresh clone has them present and
pinned. Upstreams:

- `tpm`            https://github.com/tmux-plugins/tpm
- `tmux`           https://github.com/dracula/tmux
- `tmux-continuum` https://github.com/tmux-plugins/tmux-continuum
- `tmux-resurrect` https://github.com/tmux-plugins/tmux-resurrect
- `tmux-yank`      https://github.com/tmux-plugins/tmux-yank

`prefix+U` updates a plugin in place; that then shows as a normal working-tree
diff to commit or discard.
