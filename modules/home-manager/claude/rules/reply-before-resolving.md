Never resolve a PR review thread silently. Before resolving, post a reply on the thread that says
what was done: the fix and the commit, or why the point is declined. Draft the reply text and get
the user's approval for it (external-writes.md), then post it and resolve the thread in the same
step.

This holds for every reviewer, bots like Copilot included.

Why: threads were resolved without a word after fixes, so reviewers could not see what happened to
their point.
